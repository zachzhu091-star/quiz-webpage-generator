# 选题库

来源：`[[AI测试网页项目]]`（Obsidian 库根目录）。核心逻辑：测试卖的是「自我探索」+「社交分享」，所以选题要能让用户截图发给朋友。

## 一、大众五大类（用户基数大，竞争也大）

### ① 城市类
1. 你的灵魂老家在哪座城市
2. 哪座城市最适合你定居
3. 你的宿命恋人来自哪个城市
4. 测你骨子里是南方还是北方人格
5. 哪座城市和你的气质天生相合

→ 结果类型：6 座城市（带城市气质文案：成都/杭州/西安/厦门/重庆/北京…），配色建议国风金或午夜蓝。

### ② 历史古风类
1. 测你对应哪位中国历史人物
2. 你在古代是什么身份
3. 你在仙侠世界是什么角色
4. 你的古代天赋技能
5. 你在古代会拥有什么人生剧本

→ 结果类型：谋士 / 帝王 / 文人 / 侠客 / 诗人 / 将领 / 隐士 中选 6 个；配色国风金、复古报纸。

### ③ 恋爱情感类
1. 测你的恋爱人格
2. 你容易吸引什么样的恋人
3. 你的恋爱隐藏短板
4. 情侣适配度测试（双人，需要两套结果或对比页）
5. 你的理想恋爱剧本

→ 结果类型：6 种恋爱人格（守护者/猎手/钝感力…）；配色樱花粉。

### ④ 人格天赋类
1. 你的隐藏天赋测试
2. 七宗罪人格测试
3. 你的性格底色测试
4. 你的天赋适合什么赛道
5. 你的潜意识人格

→ 结果类型：6 种天赋/底色；配色午夜蓝、赛博霓虹。

### ⑤ 情绪娱乐类
1. 你的人生隐藏剧本
2. 你是什么小动物人格
3. 你的专属氛围感标签
4. 你适合什么样的生活节奏
5. 你的人生主线任务测试

→ 结果类型：6 种小动物/生活节奏；配色奶油治愈。

## 二、小众方向（圈层属性强，更容易在小圈子里讨论）

1. 测你是哪种大学生人格
2. 测你是哪种游戏玩家
3. 测你是仙侠世界里的什么角色
4. 测你是哪种打工人（模板自带示例）
5. 测你适合经营什么样的小店
6. 测你是哪种创业者人格
7. 测你是什么宠物主人
8. 测你的旅游搭子人格
9. 测你是哪种咖啡/酒精人格
10. 测你适合哪种城市生活方式

## 三、怎么判断一个选题值不值得做

1. 去小红书搜关键词，看三件事：同类笔记**收藏**多不多、评论区有没有人**求链接**、同类虚拟商品**有没有销量**。
2. 标题里必须能放一个具体身份词（打工人、大学生、宠物主人、旅行搭子），不要泛泛的「性格测试」。
3. 结果要能被比较：「我测出来是曹操，你是什么？」——能被这样问，才会传播。
4. 避开需要专业背书的领域（抑郁、焦虑、职业测评付费结论），那是另一个赛道。

## 四、选题 → 结果类型数量建议

| 主题 | 结果数 | 题数 | 理由 |
| --- | --- | --- | --- |
| 城市 / 古风 | 6 | 20 | 类型差异大，容易写 |
| 恋爱 / 情侣 | 4–6 | 20（情侣版 15×2） | 太多了不好对号入座 |
| 人格 / 天赋 | 6–8 | 20–25 | 维度多，可以用双轴 |
| 小动物 / 氛围 | 6 | 15–20 | 图一乐，题目短一点更好 |
| 打工人 / 大学生 | 6 | 20 | 场景多，题目好写 |
