# 上线与变现清单

## 1. 部署成公开链接（三选一）

| 平台 | 适合 | 操作 |
| --- | --- | --- |
| GitHub Pages | 免费、长期 | 建仓库 → 上传 html（改名 `index.html`）→ Settings → Pages → 选 main 分支 |
| Vercel | 想快、要自定义域名 | 拖拽文件夹到 vercel.com/new |
| Cloudflare Pages | 国内访问相对稳 | pages.cloudflare.com → 上传目录 |

要点：

- 单文件落地页，文件名改为 `index.html` 才能用根路径直接打开。
- 部署后**必须**用手机流量 + 微信内置浏览器各开一次，确认能完整答题到结果页。
- 微信里如果被拦截，换域名或让用户「用浏览器打开」，并在商品详情页写清楚。

## 2. 上架与定价（小红书虚拟商品）

1. 先确认账号有虚拟商品销售资格。
2. 商品标题/封面/详情页用结果卡片截图，别用网页截图。
3. 定价参考：
   - 单个趣味测试 0.99 元
   - 三个主题合集 2.99 元
   - 完整人格探索合集 6.99 元
   - 情侣双人套餐 9.9 元
4. 支持自动交付就把测试链接 + 使用说明放进发货内容；成交链路：笔记 → 兴趣 → 下单 → 自动拿链接 → 开始答题。
5. 先公开链接验证需求，再考虑兑换码、订单校验。

## 3. 笔记文案套路

- 不要写「我的 AI 测试产品上线了」，没人关心工具。
- 写结果，让读者想知道自己是什么：
  - 「笑死，测完发现我上辈子居然是个谋士。」
  - 「测了一下我的灵魂老家，难怪我这么喜欢成都。」
  - 「朋友测出来是李白，我测出来居然是曹操。」
  - 「这个恋爱人格测试，有点东西。」
  - 「测测你的隐藏天赋到底是什么？」
- 封面直接用结果卡片（海报导出图），正文放 2–3 道有意思的题或几种结果类型。
- 结果本身就是宣传素材：用户愿意分享，产品才有二次传播。

## 4. 合规红线

- 页面保留「仅供娱乐 · 不构成任何专业评估」。
- 不宣称科学、不宣称预测命运、不做医疗/心理诊断。
- 涉及动漫影视游戏 IP 的角色，改为原创设定或泛化描述（「剑客」「谋士」而不是具体角色名）。
- 用户若要填手机号/微信，先想清楚用途，能不收集就不收集。
